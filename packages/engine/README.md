# mokhwan-engine

เอนจินคำนวณการฟุ้งกระจายของ PM2.5 จากการเผาในที่โล่ง — Gaussian plume และ Lagrangian puff
บนสนามลมที่ภูมิประเทศเบนแล้ว

ไม่มี DOM ไม่มี network ไม่มี dependency รับตัวเลขเข้า คืนกริดความเข้มข้นออก
รันได้ทั้งใน Node, Web Worker และเบราว์เซอร์ · TypeScript พร้อม type ครบ

ส่วนหนึ่งของ [Mokhwan](https://github.com/JRChanakarn/mokhwan) — **ยังไม่เคยตรวจสอบเทียบ
ค่าตรวจวัดจริง** อ่าน [ข้อจำกัด](#ข้อจำกัด) ก่อนใช้กับงานจริง

```bash
npm install mokhwan-engine
```

## ใช้งาน

```js
import { run } from 'mokhwan-engine';

const res = run(params);          // params: RunParams (ดูข้างล่าง)
res.perHour[0].max;               // ความเข้มข้นสูงสุดบนพื้น (µg/m³ เหนือพื้นหลัง)
```

เรียกได้อย่างเดียวคือ `run()` ซึ่งเลือกแบบจำลองตาม `params.model`
ตัวช่วยที่เปิดไว้ด้วยคือ `sigmas` `plumeRise` `windField` `runPuff` และ `SIGMA_WS_FLOOR_DEFAULT`

### รายงานความคืบหน้า

การคำนวณเป็นแบบ synchronous ทั้งก้อน ถ้าอยากอัปเดต UI ระหว่างทางให้ส่ง hook เข้าไป

```js
run(params, { onProgress: (h, nH) => console.log(`ชั่วโมงที่ ${h}/${nH}`) });
```

hook รันอยู่ในลูปของเอนจิน ถ้ามันโยน exception การคำนวณจะตายกลางคันและผลหายทั้งชุด
— **ห่อ try/catch ไว้เองในฝั่งผู้เรียก**

## `RunParams`

| ฟิลด์ | ชนิด | ความหมาย |
|---|---|---|
| `model` | `'gauss' \| 'puff'` | ปริยาย `'gauss'` |
| `fires` | `Fire[]` | แปลงที่เผา (ดูล่าง) |
| `hours` | `HourWx[]` | อากาศรายชั่วโมง หนึ่งตัวต่อชั่วโมงที่จำลอง |
| `weights` | `number[]` | สัดส่วนการปล่อยของแต่ละชั่วโมง รวมกันได้ 1 |
| `progress` | `number[]` | ความคืบหน้าการเผาสะสม 0..1 ของแต่ละชั่วโมง |
| `grid` | `GridSpec` | `{N, R, cx, cy}` — กริด N×N ครอบ ±R เมตร ศูนย์กลางที่ `(cx, cy)` |
| `receptors` | `[number, number][]` | จุดรับผลกระทบ เมตรเทียบ origin |
| `bg` | `number` | PM2.5 พื้นหลัง (µg/m³) ใช้กับการนับพื้นที่เกินเกณฑ์ |
| `avg` | `number` | เวลาเฉลี่ย (นาที) ใช้ปรับ σy ตามกฎกำลัง 0.2 |
| `depo` | `boolean` | เปิดการตกสะสมแห้ง (VD 0.004 m/s) และการชะด้วยฝน |
| `reqId` | `number` | ตัวกันผลค้าง เอนจินคืนกลับมาใน `res.reqId` ให้ฝั่งเรียกเทียบเอง |
| `elev` | `Float32Array \| null` | DEM ขนาด N×N เมตร เรียงตรงกับกริด — **โหมด `puff` เท่านั้น** |
| `sigmaWsFloor` | `number` | พื้นความเร็วลมอ้างอิงสำหรับการโตของ σ (m/s) ปริยาย 1.0 · `0` = ปิด |

### `Fire`

| ฟิลด์ | ความหมาย |
|---|---|
| `pts` | จุดปล่อยย่อยในแปลง `[x, y]` เมตรเทียบ origin — แปลงใหญ่ควรซอยหลายจุด |
| `side` | ความกว้างแปลง (m) ใช้ตั้ง σy ตั้งต้นให้พลูมไม่แคบเกินจริง |
| `fuelKg` | เชื้อเพลิงที่ไหม้ (kg) |
| `totalG` | PM2.5 ที่ปล่อยทั้งหมด (g) = `fuelKg × emission factor` |
| `smold` | สัดส่วนเฟสคุกรุ่น 0..1 · ยิ่งเชื้อเพลิงชื้นยิ่งสูง ควันส่วนนี้ลอยต่ำและเป็นตัวหลักของค่าที่พื้น |
| `rai` | ขนาดพื้นที่เป็นไร่ ใช้รายงานเท่านั้น ไม่เข้าการคำนวณ |

### `HourWx`

| ฟิลด์ | ความหมาย |
|---|---|
| `t` | คีย์เวลา `'YYYY-MM-DDTHH:mm'` |
| `dt` | ความยาวช่วง (วินาที) ปกติ 3600 |
| `ws` `wdir` | ความเร็วลม (m/s) และทิศที่ลม**มาจาก** (องศา) |
| `stab` | Pasquill `'A'`–`'F'` |
| `mix` | ความสูงชั้นผสม (m) |
| `precip` | ฝน (mm/hr) ใช้คำนวณการชะ `Λ = 1e-4·P^0.7` |
| `temp` `rh` | อุณหภูมิ (°C) และความชื้นสัมพัทธ์ (%) — `null` ได้ ใช้รายงานเท่านั้น |
| `windU` `windV` | สนามลมรายเซลล์ N×N (m/s) — **ไม่บังคับ** ถ้าส่งมาจะใช้แทน `ws`/`wdir` เป็นลมพื้นฐาน แล้วภูมิประเทศเบนทับ |

`windU`/`windV` เรียงตรงกับกริด แถว `j=0` คือเหนือสุด · `ws`/`wdir` ยังถูกใช้กับการยกตัว
ของพลูมและการโตของ σ ซึ่งเป็นสมบัติที่จุดกำเนิด จึงต้องส่งมาเสมอแม้มีสนามลมแล้ว

## `RunResult`

| ฟิลด์ | ความหมาย |
|---|---|
| `grids` | `Float32Array[]` หนึ่งใบต่อชั่วโมง แต่ละใบ N×N เรียงจากแถวเหนือสุด (µg/m³ เหนือพื้นหลัง) |
| `maxGrid` | ค่าสูงสุดตลอดช่วงของแต่ละเซลล์ |
| `doseGrid` | ผลรวมตลอดช่วง หารด้วย 24 แล้วได้ค่าเฉลี่ย 24 ชั่วโมง |
| `N` `cell` `cx` `cy` `R` | เรขาคณิตของกริดที่ใช้จริง `cell = 2R/N` |
| `meanUx` `meanUy` | เวกเตอร์ลมเฉลี่ยหนึ่งหน่วย ใช้วาดทิศที่ควันไป |
| `perHour` | สรุปรายชั่วโมง — ความสูงพลูม อัตราปล่อย ค่าสูงสุดและระยะที่เกิด `Fr` `relief` |
| `recPerHour` `recMax` `recDose` | ค่าที่จุดรับผลกระทบ |
| `totalEmitKg` `totalFuelT` | PM2.5 ที่ปล่อยรวม (kg) และเชื้อเพลิงที่ไหม้รวม (ตัน) |

## โหมด `puff` กับภูมิประเทศ

ส่ง `elev` เป็น DEM ขนาด `N×N` (เมตรจากระดับน้ำทะเล) เรียงตรงกับกริด
เอนจินจะสร้างสนามลมวินิจฉัยจาก DEM นั้นแล้วเดินก้อนควันไปบนสนามลมนั้น

```js
run({ ...params, model: 'puff', elev: demGrid });
```

`res.perHour[i].Fr` คือ Froude number ของชั่วโมงนั้น — ต่ำกว่า 1 หมายถึงลมถูกภูเขาปิดกั้น
และเบนอ้อมมากกว่าพุ่งข้าม · `res.perHour[i].relief` คือความต่างระดับในโดเมน (m)

### `sigmaWsFloor` — ต้องเข้าใจก่อนปรับ

โมเดล puff ให้ σ โตตามระยะทางที่ก้อนควันเดิน พอลมหลักถูกภูมิประเทศหักล้างจนก้อนควัน
ชะงักในแอ่ง σ จึงหยุดโตและควันไม่เคยกระจายลงถึงพื้น ค่านี้ตั้งพื้นให้ σ ยังโตเทียบเท่า
ลม n m/s แม้ก้อนควันจะหยุด

**เป็นสมมติฐานเชิงแบบจำลอง ไม่ใช่ค่าที่วัดมา** เส้นโค้ง Briggs ฟิตจากพลูมที่ถูกลมพัด
การใช้ `ws·t` เป็นตัวแทนระยะจึงเป็นการประมาณเชิงวิศวกรรม ตั้ง `0` เพื่อปิด (จะได้พฤติกรรม
ก่อนแก้บั๊ก ซึ่งให้ค่าที่พื้นแทบเป็นศูนย์บนภูมิประเทศจริง)

## สูตรทั้งหมด

[`docs/model.md`](https://github.com/JRChanakarn/mokhwan/blob/main/docs/model.md)
มีทุกสูตรที่เอนจินใช้ พร้อมอ้างไฟล์และฟังก์ชัน — การยกตัวแบบ Briggs, σ ของ
open-country, การสะท้อนที่ชั้นผสม, สนามลมวินิจฉัยจาก DEM, การตกสะสมและฝนชะ
และตารางแยกว่าค่าไหนวัดมาจริง ค่าไหนสมมติขึ้น

## ข้อจำกัด

- **ยังไม่เคยตรวจสอบเทียบค่าตรวจวัดจริง**
- คืนความเข้มข้นที่**ระดับพื้น**เท่านั้น ไม่มีสนาม 3 มิติ
- สนามลมของโหมด `puff` เป็นแบบ**วินิจฉัยสองมิติ** จับไม่ได้เรื่องคลื่นภูเขา
  การแยกตัวของกระแสหลังสันเขา และการสะสมข้ามวันใต้อินเวอร์ชัน
- โหมด `gauss` สมมติพื้นราบและลมคงที่ในแต่ละชั่วโมง
- งานระดับที่ใช้ตัดสินใจเชิงนโยบายต้องใช้ CALPUFF หรือ WRF-Chem
