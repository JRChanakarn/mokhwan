# Mokhwan

จำลองการฟุ้งกระจายของ PM2.5 จากการเผาในที่โล่ง สำหรับภาคเหนือของไทยช่วงฤดูหมอกควัน

วางแปลงที่จะเผาลงบนแผนที่ กรอกชนิดเชื้อเพลิงกับขนาดพื้นที่ แล้วดูว่าควันจะไปทางไหน
เข้มเท่าไร และกระทบโรงเรียนหรือโรงพยาบาลที่อยู่ใกล้แค่ไหน — เพื่อช่วยตัดสินใจว่าจะเผา
วันไหน เวลาไหน หรือไม่เผาเลย

**[ลองใช้ที่นี่](https://jrchanakarn.github.io/mokhwan/)**

**ยังไม่เคยถูกตรวจสอบเทียบค่าตรวจวัดจริง** อ่าน [ข้อจำกัด](#ข้อจำกัด) ก่อนใช้กับงานจริง

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `packages/engine` | `mokhwan-engine` — เอนจินคำนวณล้วนๆ ไม่มี DOM ไม่มี network เอาไปใช้ที่ไหนก็ได้ |
| `app` | แอปตัวอย่างที่ใช้เอนจินตัวนั้น (Leaflet 2D + MapLibre 3D) |

เอนจินไม่รู้จักแผนที่ ไม่รู้จักเบราว์เซอร์ รับตัวเลขเข้า คืนกริดความเข้มข้นออก
จึงเอาไปรันใน Node, Web Worker หรือฝังในแอปอื่นได้โดยไม่ต้องลากทั้ง UI ไปด้วย

## เริ่มใช้

```bash
npm install
npm run dev -w app          # เปิดที่ http://localhost:5173
npm test                    # เทสต์เอนจินและโมดูลของแอป
npm run test:smoke          # เทสต์ UI จริงใน Chrome (ต้องมี dev server ที่พอร์ต 5180)
```

`npm run test:smoke` ปิดเน็ตจริงทั้งหมด คำขอที่ออกนอก origin ถูกดักและตอบด้วยไทล์ว่าง
จึงรันได้แม้เน็ตถูกจำกัด และยังยืนยันได้ว่าแอปคุยกับ host ภายนอกตัวไหนบ้าง

## ใช้เอนจินอย่างเดียว

```bash
npm install mokhwan-engine
```

```js
import { run } from 'mokhwan-engine';

const res = run({
  model: 'gauss',                          // 'puff' = ตามภูมิประเทศ ต้องส่ง elev มาด้วย
  fires: [{
    pts: [[0, 0]],                         // จุดปล่อย เมตรเทียบ origin
    side: 490,                             // ความกว้างแปลง (m) ใช้ตั้ง σy ตั้งต้น
    fuelKg: 90_000, totalG: 855_000,       // เชื้อเพลิง (kg) และ PM2.5 ที่ปล่อย (g)
    smold: 0.4,                            // สัดส่วนเฟสคุกรุ่น 0..1
    rai: 150,
  }],
  hours: [{
    t: '2026-03-01T10:00', dt: 3600,
    ws: 2.1, wdir: 225,                    // ม./วิ และทิศที่ลม**มาจาก** (องศา)
    stab: 'C', mix: 900,                   // Pasquill A–F และความสูงชั้นผสม (m)
    precip: 0, temp: 31, rh: 45,
  }],
  weights: [1], progress: [1],
  grid: { N: 180, R: 10_000, cx: 0, cy: 0 },
  receptors: [[1200, -300]],
  bg: 25, avg: 60, depo: true, reqId: 1,
});

res.perHour[0].max;        // ความเข้มข้นสูงสุดบนพื้นชั่วโมงนั้น (µg/m³ เหนือพื้นหลัง)
res.grids[0];              // Float32Array ขนาด N×N เรียงจากแถวเหนือสุด
res.recPerHour[0][0];      // ค่าที่จุดรับผลกระทบตัวแรก
```

รายละเอียดของทุกฟิลด์อยู่ใน [`packages/engine/README.md`](packages/engine/README.md)

## เอกสาร

**[สแตกและสูตรคำนวณทั้งหมด](docs/model.md)** — ทุกสูตรอ้างไฟล์และฟังก์ชันที่ใช้จริง
พร้อมตารางแยกว่าเลขไหนวัดมาจริง เลขไหนสมมติขึ้น และรายการสิ่งที่แบบจำลองไม่คิด 11 ข้อ

## แบบจำลอง

เลือกได้สองแบบผ่าน `model`

**`gauss`** — Gaussian plume ระดับคัดกรอง สมมติพื้นราบและลมคงที่ในแต่ละชั่วโมง
เร็วพอจะเปรียบเทียบทางเลือกได้ทันทีขณะลากสไลเดอร์

**`puff`** — Lagrangian puff เดินบนสนามลมวินิจฉัยสองมิติที่ภูมิประเทศเบนแล้ว
ต้องส่ง `elev` (DEM ขนาด N×N) เข้ามาด้วย จับได้เพิ่มคือ

- ลมเบนอ้อมภูเขาแทนที่จะพุ่งทะลุ (ตาม Froude number)
- ลมไหลลงลาดตอนกลางคืน (drainage flow)
- การอับลมในแอ่ง

ทั้งสองแบบใช้ σ ของ Briggs open-country การยกตัวของพลูมแบบ Briggs การสะท้อนที่ชั้นผสม
การตกสะสมแห้ง และการชะด้วยฝน

## ข้อจำกัด

**อ่านตรงนี้ก่อนเอาไปใช้ตัดสินใจอะไรจริงจัง**

- **ยังไม่เคยตรวจสอบเทียบค่าตรวจวัดจริง** ตัวเลขที่ได้คือผลของแบบจำลอง ไม่ใช่ค่าที่วัดได้
- โหมด `puff` ใช้สนามลม**วินิจฉัยสองมิติ** จับไม่ได้เรื่องคลื่นภูเขา การแยกตัวของกระแส
  หลังสันเขา และการสะสมข้ามวันใต้อินเวอร์ชัน — งานระดับนโยบายต้องใช้ CALPUFF หรือ WRF-Chem
- โหมด `gauss` สมมติพื้นราบ ไม่คิดการไหลลงร่องเขาตอนกลางคืนเลย
- `sigmaWsFloor` เป็น**สมมติฐานเชิงแบบจำลอง ไม่ใช่ค่าที่วัดมา** (ดูเหตุผลใน `types.ts`)
- ค่าเชื้อเพลิงต่อไร่และ emission factor เป็นค่ากลางของชนิดพืช ของจริงต่างกันได้หลายเท่า
- ในแอป ความหนาของควันในแนวดิ่งที่เห็นในมุมมอง 3D **สร้างขึ้นจาก σz** ไม่ใช่ผลการคำนวณ
  เอนจินคืนความเข้มข้นที่ระดับพื้นเท่านั้น — รูปร่างแนวราบและตัวเลขความเข้มข้นคือของจริง

### สิ่งที่แบบจำลองไม่คิด

เรียงตามผลกระทบต่อตัวเลข — รายละเอียดและเหตุผลอยู่ใน [`docs/model.md`](docs/model.md#สิ่งที่แบบจำลองไม่คิด)

1. **`EF` แยกตามเฟสการเผาได้แล้ว แต่ค่าปริยายยังเป็น 1** — มีพารามิเตอร์ `efRatio`
   (ปรับได้ใน UI) ที่ย้ายมวลฝุ่นไปอยู่กับควันคุกรุ่นที่ลอยต่ำ โดยมวลรวมที่ปล่อยไม่เปลี่ยน
   Oanh et al. (2011) วัดฟางข้าวในไทยได้อัตราส่วนเผากอง/เผากระจาย ≈ 4.3 เท่า
   ค่าปริยายยังเป็น 1 เพราะการเปลี่ยนขยับผลลัพธ์ทุกตัว ควรทำหลังตรวจสอบเทียบค่าจริง
2. **อนุภาคทุติยภูมิ (SOA)** ไม่มีเลย มวล PM ของควันชีวมวลโตได้หลังปล่อย → ต่ำกว่าจริงในระยะไกล
3. **Fumigation** ควันติดใต้อินเวอร์ชันกลางคืนแล้วถูกคลุกลงพื้นตอนเช้า — เคสค่าสูงสุดคลาสสิกที่จับไม่ได้
4. **การสะสมข้ามวัน** ก้อนควันหมดอายุที่ 4 ชม. แต่ปัญหาจริงของฤดูหมอกควันคือสะสมหลายวัน
5. **ควันจากที่อื่น** พื้นหลังเป็นค่าเดียวต่อชั่วโมง ไม่มีการพัดพาจากไฟข้างเคียง
6. **ความขรุขระผิวและเรือนยอด** ใช้ Briggs open-country ชุดเดียว ป่ากับไร่อ้อยคนละเรื่อง
7. **ลมเปลี่ยนทิศตามความสูง** มีแค่เปลี่ยนความเร็ว ไม่มี directional shear
8. **`Vd` เป็นค่าคงที่ 0.004 ม./วิ** ของจริงขึ้นกับผิวและขนาดอนุภาค
9. **ความชื้นสัมพัทธ์เก็บมาแต่ไม่ใช้คำนวณ**
10. **พลูมหลายกองไม่รวมแรงยกตัวกัน** และไม่มีแบบจำลองการลามของไฟ
11. **คลื่นภูเขาและการแยกตัวของกระแสหลังสันเขา** สนามลมเป็นแบบวินิจฉัยสองมิติ

แอปมีสวิตช์ **โหมดข้อมูลจริง** ที่ปิดตัวคูณเพื่อการมองเห็นทุกตัว บังคับใช้ DEM จริง
สนามลมรายจุดจริง และพยากรณ์จริง พร้อมป้ายแยกให้เห็นว่าเลขไหนวัดมา เลขไหนมาจากแบบจำลอง
